About this plugin

Design System Doctor looks for inconsistent use of color, spacing, and radius tokens; missing shared typography styles; unresolved component instances; layout gaps; and unclear layer names. It brings those signals into a prioritized report so a team can decide what to repair first.

The plugin diagnoses without modifying source layers. Balanced and strict modes let you adjust the review depth to match the maturity of the file and system.

How to use it

  1. Open the plugin from this page in a Figma Design file.
  2. Choose scope and depth for the selection or current page.
  3. Create a diagnosis report and prioritize the fixes with your team.

A COMPLETE TASK

Follow the decision, including recovery.

  1. Compare depth on one source

    Run Balanced and Strict against the same sample and inspect the additional adoption questions.

  2. Check an alias

    Keep an intentional campaign alias when the source context justifies the variation.

  3. Repair actual drift

    Bind the sample to its intended token, then rescan the same scope to see exactly what changed.

  4. Read uncertainty

    No findings, capped findings, unavailable libraries and interrupted assessment have different meanings.

DECISIONS AND TRADEOFFS

Why this behavior earns its place.

Use the available system evidence

A literal color is not automatically wrong. The scanner can inspect bindings and shared styles, but cannot infer every intended design-system exception.

Tradeoff. Unresolved libraries and aliases require a maintainer’s judgment. The report must say when evidence is unavailable.

Make depth consequential

Balanced mode emphasizes structural risks. Strict mode includes additional adoption/naming questions for mature systems.

Tradeoff. More findings may add noise. The sample lets a reviewer compare modes on the same source.

Repair, then rescan the same scope

A diagnosis is useful when its recommendation leads to a specific correction and the follow-up identifies what changed.

Tradeoff. A health summary is a scope-specific description, not a universal score for design quality.
