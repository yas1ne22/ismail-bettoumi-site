# Nasaq — Violet identity

An Arabic-first design system with a Material-inspired presentation: violet accents, lavender surfaces, generous type, and rounded geometry.

The original five connected units remain the Nasaq symbol. Corners are softly rounded. Preserve the arrangement, proportions and reading direction; do not mirror the symbol. Leave a quarter of its width clear on each side. Minimum sizes: 24px for the mark, 100px for a lockup.

Use violet #6442CC on pale surfaces, lavender #D4BFFF on dark surfaces, and the paper variant on violet. Canvas #FFFBFF, surface #F6F0F7, selected #E8DEF8, text #201D22, secondary text #625D67. Rounded cards use 24–28px corners; calls to action are pills.

Almarai for Arabic and Inter for English. The lockups retain editable text and embedded Almarai; install the bundled fonts when editing in software that does not retain embedded fonts. Keep Arabic letter spacing at zero.

These are brand and presentation colors. Component implementation tokens remain documented separately in the design system. Status colors retain their semantic meanings.

Original Nasaq assets; Material Design 3 is the presentation reference. Fonts and Lucide icons retain their accompanying licenses.
