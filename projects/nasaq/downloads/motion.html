الحركة والتفاعل

حركة قصيرة تشرح التغيير، وتفاعل يحترم المستخدم. المتغيرات تغطي الوقت والمنحنى والمسافة، ثم تربطها المكونات بإجراءات واضحة.

جرّب الحركة والتفاعل

يحترم النظام أيضًا تفضيل reduced-motion في جهازك. التركيز يظهر فورًا، ولا يخفيه أي انتقال.

01 / EASING

بداية، ووصول.

مثال حركة؛ لا يمثل تقدم عملية.

02 / REVEAL

محتوى عند الطلب.

التفاصيل أصبحت متاحة.

إزاحة 8px، مدة 320ms. يبقى المحتوى في ترتيب قراءة طبيعي.

03 / PRESS + FOCUS

استجابة صغيرة.

Hover 120ms؛ press scale 0.98؛ Focus فوري. جرّب Tab ثم Space.

04 / DIALOG

قرار في مكانه.

نافذة توضيحية

دخول 200ms. Escape يغلق ويعيد التركيز. لا تؤخر الإغلاق.

05 / LOADING

حركة، بلا ادعاء.

العرض متوقف.

تشغيل محلي للحركة فقط. لا طلب ولا توليد AI. أوقف التحميل عند الوصول أو الخطأ في المنتج الحقيقي.

06 / DISCLOSURE

تفاعل أصلي.

ما الذي يحدث عند تقليل الحركة؟

لا انتقال ولا دوران. تبقى الحالات والنصوص والأفعال واضحة وقابلة للاستخدام.

الوصفة في مشروعك

.nq-enter {
 animation:nq-enter var(--nq-interaction-reveal-duration)
           var(--nq-interaction-reveal-easing) both;
}
@keyframes nq-enter {
 from {opacity:0;transform:translateY(var(--nq-motion-distance-md))}
 to   {opacity:1;transform:translateY(0)}
}
@media (prefers-reduced-motion:reduce) {
 *, *::before, *::after {animation:none!important;transition:none!important}
}
