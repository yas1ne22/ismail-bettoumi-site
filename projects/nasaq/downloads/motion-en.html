What changes with reduced motion?

No transition or rotation. Text, state and actions remain available.

Implementation rules

Focus is immediate. Hover never contains exclusive information. Press feedback must not replace the action. Reveal uses aria-expanded and hidden. Dialog uses native focus containment and Escape. Loading stops when work succeeds or fails, and includes a written status.

@media (prefers-reduced-motion:reduce) {
 *,*::before,*::after { animation:none!important; transition:none!important; }
}
