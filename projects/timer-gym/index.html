A COMPLETE TASK

Follow the decision, including recovery.

  1. Read the phase

    Prepare, Work, Rest and Complete use text labels and remaining time, with the next phase named.

  2. Remove a cue

    Disable phase color and leave optional speech off. Phase, position, remaining time and controls remain visible as text. Unsupported or failed speech is labeled; haptics are not provided in this browser study.

  3. Pause across a transition

    An interruption projects elapsed time to the current phase before retaining the remaining time.

  4. Review a restart

    Opening restart review pauses first and shows the retained phase/time. Keep session leaves it paused; only explicit confirmation resets it. Returning from the browser cache also stays paused.

DECISIONS AND TRADEOFFS

Why this behavior earns its place.

State before decoration

A large remaining time needs a named phase and round context. Color alone cannot explain the next action.

Tradeoff. Audio, haptics and screen visibility can each be unavailable; defaults need physical-context evaluation.

Make interruption reversible

The browser study settles elapsed time before pausing and keeps controls in place through phase changes. Restart review pauses first and exposes the current phase/time before confirmation.

Tradeoff. Canceling a restart or returning to the page keeps the session paused. This explicit resume boundary is a design choice that still needs observation during movement.

Keep the timing core independent

The useful timer should work without account setup, coaching media or an equipment-scanning service.

Tradeoff. The broader training ecosystem remains gated by configuration and content review, as documented in the case.
