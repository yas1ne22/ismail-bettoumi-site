The behavior

The web remembers everything.
Finding it again is the hard part.

Bookmarks become archives. Tabs become anxiety. Useful tools disappear inside browser chrome. The product opportunity was not another link manager. It was a calmer way to return to the web.

Recall costs attention

People remember what a site does before they remember where they saved it.

Tools and inspiration compete

Work links, build tools, creative references, and learning resources share one flat list.

Discovery rarely becomes action

Interesting content arrives in feeds, then vanishes before it reaches a useful workflow.

A COMPLETE TASK

Follow the decision, including recovery.

  1. Start without permissions

    Inspect sample content or start empty. Optional permission refusal leaves manual capture available.

  2. Capture a reference

    Add a valid URL and destination. An absent title falls back to the host; equivalent URLs do not create duplicates.

  3. Find, open and reorganize

    Search across destinations, open a saved title in a new tab, move a reference or delete a category by moving its links to another destination.

  4. Recover the workspace

    Keep an unfinished capture through search and destination changes. Reveal an existing duplicate, undo removal, then export a JSON copy and review its validated contents before replacement.

DECISIONS AND TRADEOFFS

Why this behavior earns its place.

Organize around a return task

A flat archive minimizes initial decisions but can make later retrieval expensive. The four destinations make a hypothesis about everyday contexts visible.

Tradeoff. Work, Build, Create and Learn can overlap. They need testing, and users need a clear way to move an item.

Capture with one necessary choice

Quick add starts with a recognized site and one destination, then confirms where it went.

Tradeoff. Duplicate links, missing titles and category changes need explicit recovery rather than silent overwrites.

Keep discovery secondary

The workspace is the primary utility. Editorial rails can provide a return reason only if they do not compete with finding a saved site.

Tradeoff. Comparative task evidence is still needed to justify feed density and default placement.

Evaluate the return task before expanding discovery.

Keep. Keep capture short, name the destination and provide a visible way to move or recover a saved site. The local organizer now handles equivalent URLs and stale removal undo explicitly.

Change next. Test ambiguous links against Work, Build, Create and Learn before extending the taxonomy. Keep discovery optional while the value of the saved-site workflow is being established.
